# Timken

The Timken Company is a global manufacturer of engineered bearings and industrial motion products including ball bearings, tapered roller bearings, seals, lubrication systems, gear drives, belts, clutches, couplings, and related motion control products serving aerospace, automotive, industrial, and energy markets.

## APIs

### Timken Engineering Tools

Interactive engineering tools for bearing selection, bearing life calculation, tolerance lookup, lubrication, gear force calculations, and precision bearing selection.

- **Documentation:** [https://engineering.timken.com/engineering-tools/](https://engineering.timken.com/engineering-tools/)
- **Website:** [https://engineering.timken.com/](https://engineering.timken.com/)

## Features

- Bearing Search and Selection
- Bearing Fatigue Life Calculation
- Bearing Tolerance Lookup
- Bearing Clearance Calculations
- Grease Lubrication Calculator
- Gear Force Calculations
- Unit Conversion Tool
- Precision Bearing Selector
- CAD Drawing Downloads

## Use Cases

- Bearing selection for industrial machinery
- Life estimation for bearing applications
- Lubrication system design
- Gear drive engineering calculations
